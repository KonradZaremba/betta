Build a small Grasshopper plugin for facade panel fabrication in this project. Every component goes in category "Facade". It's a new library, so organise the code as you see fit.

A panel is one four-sided piece cut from a surface. It knows its four corners (in order around the panel), its outline, its area, its planarity deviation (the distance from the fourth corner to the plane through the other three) and its index in the grid. Components pass panels to each other as one "Panel" value per panel, on a wire of their own; not as loose numbers or points.

Components (subcategory in brackets; inputs, then outputs):

1. Panelize Surface [Panels]. Inputs: Surface, U Count (integer, default 10), V Count (integer, default 6). Outputs: Panels, Outlines (closed curves). Divide the surface's domain evenly; a panel's corners are the surface points at its grid cell's corners. If U Count or V Count is below 1, show an error and output nothing.
2. Panel Info [Panels]. Input: Panel (one). Outputs: Corners (4 points), Outline, Area, Center, Index.
3. Planarity [Analysis]. Inputs: Panels, Tolerance (number, default 0.5). Outputs: Deviation (one per panel), Flat (one boolean per panel, Deviation at most Tolerance), Flat Count. If more than half the panels are not flat, show a warning that says how many, and still output everything.
4. Classify Panels [Analysis]. Inputs: Panels, Tolerance (default 0.5). Outputs: Type (one text per panel: "flat" when Deviation is at most Tolerance, "cold-bent" when at most 10 times Tolerance, otherwise "custom"), Flat Count, Cold Bent Count, Custom Count.
5. Panel Stats [Analysis]. Input: Panels. Outputs: Total Area, Min Area, Max Area, Mean Area. If there are no panels, show an error and output nothing.
6. Group Identical Panels [Fabrication]. Inputs: Panels, Tolerance (default 1.0). Outputs: Group (a group number per panel, numbered in order of first appearance from 0), Group Count, Representatives (the first panel of each group). Two panels are identical when their four edge lengths, sorted, and their two diagonal lengths, sorted, each differ by at most Tolerance.
7. Nest On Sheets [Fabrication]. Inputs: Panels, Sheet Width (default 3000), Sheet Height (default 1500), Spacing (default 10; the gap between parts and from the sheet edge). Outputs: Outlines (each placed panel's rectangle as a closed curve, sheets laid out side by side along X, Sheet Width + 100 apart), Sheet (the sheet index of each placed panel, same order as Outlines), Sheet Count, Utilization (placed rectangle area divided by Sheet Count times the sheet area). Each panel is nested as a rectangle: width is the mean of its first and third edge lengths, height the mean of its second and fourth. Use a shelf algorithm: tallest first, fill shelves left to right, start a new shelf above when a part doesn't fit, a new sheet when a shelf doesn't fit, and turn a part 90 degrees when it only fits turned. This can take a while on big facades: run it without freezing Grasshopper, stop the old run when the inputs change, and show progress. If some panels fit on no sheet, show a warning that says how many, and still output the rest.
8. Cut List [Fabrication]. Inputs: Panels, Path (text, default empty), Write (boolean, default false). Outputs: CSV (text with a header line and one line per panel: index, width, height, area, deviation, using the same width and height as Nest On Sheets), Written (boolean). Write the CSV to Path only when Write is true; if Write is true and Path is empty, show an error.

Follow the pattern this project already uses. Don't ask questions; make reasonable choices. You are done when `dotnet build` succeeds.
